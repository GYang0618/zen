# 功能清单（Feature Catalog）

> 状态：设计基线  
> 相关：[平台总览](../architecture/platform-overview.md) · [实施路线](../implementation/roadmap.md) · [插件系统](../architecture/plugin-system.md)

本文档定义 2026 现代化后台管理平台应具备的能力。每项标注：

- **优先级**：P0 必须 / P1 强烈建议 / P2 按需演进
- **归属**：`kernel`（平台内核）或 `plugin`（插件交付）
- **阶段**：对应 [roadmap](../implementation/roadmap.md) 的 Phase
- **验收**：可验证结果，避免仅按代码完成度验收

---

## 1. P0 · 平台底座

### 1.1 认证与会话

| ID | 能力 | 归属 | 阶段 | 验收 |
|----|------|------|------|------|
| AUTH-01 | 账号密码登录 / 登出 | kernel | 1 | 登录签发 Access + Refresh；登出使会话失效 |
| AUTH-02 | Access + Refresh Token 轮换与服务端撤销 | kernel | 1 | Refresh 轮换；主动登出 / 强制下线生效 |
| AUTH-03 | 登录失败锁定与防爆破 | kernel | 1 | 阈值内锁定；锁定到期自动解锁 |
| AUTH-04 | 会话列表与强制下线 | kernel | 1 | 可列出当前用户会话并逐条撤销 |
| AUTH-05 | 忘记 / 重置密码 | kernel | 1 | 安全令牌重置；旧会话全部失效 |
| AUTH-06 | 首次登录强制改密（策略可配） | kernel | 1 | 策略开启时拦截至改密页 |

### 1.2 用户管理

| ID | 能力 | 归属 | 阶段 | 验收 |
|----|------|------|------|------|
| USER-01 | 用户 CRUD、启停、软删除 | kernel | 1 | 列表/详情/创建/更新/启停/软删闭环 |
| USER-02 | 用户资料（头像、联系方式、工号等） | kernel | 1 | 资料与账号分离存储并可更新 |

| USER-04 | 管理员重置密码、解锁账号 | kernel | 1 | 需 `system:user:update`；写审计 |
| USER-05 | 用户详情聚合（角色、组织、登录审计） | kernel | 1 | 单页展示归属与最近登录 |

|----|------|------|------|------|

| RBAC-05 | 数据范围 DataScope | kernel | 1 | ALL / ORG_AND_CHILD / ORG / SELF / CUSTOM 生效于列表查询 |

## 5. 归属与阶段汇总

| 归属 | 典型能力 |
|------|----------|
| **kernel** | 认证、用户、组织、RBAC、菜单 Shell、配置、审计、插件运行时、租户上下文、文件与对象存储 |
| **plugin** | 通知、任务、Webhook、报表、AI 业务、SSO、垂直业务（BIM/GIS 等） |

| Phase | 聚焦 |
|-------|------|
| **0** | CI、测试、OpenAPI、Trace、文档门禁 |
| **1** | 平台内核（身份 / 组织 / RBAC / 菜单 / 审计） |
| **2** | 插件内核（SDK / Manifest / 贡献点） |
| **3** | 参考插件打通 |
| **4** | 能力型插件 + 脚手架 |
| **5** | 生产化与条件触发的演进项 |

## 6. 刻意不做（第一版）

- 完整低代码 / 表单设计器全家桶
- BPMN 级自研工作流引擎
- 第三方不可信插件沙箱 / WASM 隔离
- 一上来 OpenFGA / Zanzibar
- 微前端多仓拆分（优先单体前端 + 插件包边界）
- 第一版完整多租户运营后台

## 7. 「现代化」验收十条

1. 菜单、按钮、API、DataScope 权限闭环  
2. 组织树 + 主职兼职 + 数据过滤真实生效  
3. Token 可撤销、锁账号、审计可追  
4. 多页签、列设置、暗色、空错态统一  
5. 重导出异步化；大列表可分页  
6. TraceId、健康检查、结构化日志  
7. 权限码规范、字典驱动、OpenAPI 契约  
8. 插件 Manifest + SDK + 参考插件可复用  
9. 敏感字段脱敏、敏感操作确认  
10. AI Tool（若启用）有权限边界与调用审计
